# Передача проверки

Перед отправкой задания прочитать [контракт лаборатории](../../../lab/README.md) и указать владельцу цель, точную команду, окружение и ожидаемый результат.

Пакет проверки живёт в `<exchange>/checks/<id>/`. В `request.md` передать запрос, а запуск владелец выполняет через:

```text
python3 lab/run-check.py --exchange <path> --id <id> --request <request.md> -- <command> ...
```

Агент не запускает команду, не управляет стендом и не делает polling или retries. После передачи завершить ответ. Когда владелец вернётся, сначала читать `request.md`, `run.json`, `exit.txt`, затем только нужные фрагменты `output.log` и файлы `results/`. Отсутствие `exit.txt` означает незавершённый автоматический запуск; для ручного опыта читать отчёт владельца `result.md`, не требуя машинного кода. Анализировать только переданный идентификатор и версию исходников, не подменяя отсутствующий результат новым прогоном.

Указать итог: что подтвердилось, что не проверено и какая следующая правка нужна. Простое извлечение чисел из больших журналов делегировать luna с точными путями и вопросом, без полного контекста проекта. Скрипты анализа готовых журналов не должны обращаться к стенду или запускать продукт.
