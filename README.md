# psdoctor

Доктор проектов для ProShow Producer. Не заменяет мёртвую программу, а обслуживает её снаружи: осматривает проект и окружение, человеческим языком говорит, что именно поедет, и чинит по кнопке.

Photodex закрылись около 2020 года. ProShow остался 32-битным и без сопровождения: его проекты грузятся десятки минут, он виснет на рендере и не объясняет, что не так. Между «программа мертва» и «программа работает нормально» лежит не переписывание, а обслуживание.

## Один факт, из которого следует всё остальное

32-битный процесс имеет 2 ГБ адресного пространства. Картинки одного разобранного боевого проекта занимают **1.74 ГБ распакованными** — только картинки, без видео и рабочих копий. С потолком в 1080p было бы 0.67 ГБ, в 2.6 раза меньше.

Они не помещаются и не поместятся никогда: ни двадцать ядер, ни 64 ГБ памяти не помогают, потому что программа не может столько адресовать. Единственный рычаг — уменьшать объём распакованных пикселей.

## Состав

```text
src/PsDoctor.Core             модель .psh, правила, диагнозы, арифметика. Без I/O и без Windows
src/PsDoctor.Infrastructure   файлы, кодировки, процессы, Win32, ffmpeg
src/PsDoctor.Cli              прогон и отчёт без интерфейса
src/PsDoctor.App              Avalonia: отчёт, одна кнопка, трей
tests/PsDoctor.Core.Tests     xunit
inbound/                      двор для пациентов, в историю не попадает
```

## Сборка

```bash
dotnet test PsDoctor.slnx
```

Ядро и CLI собираются и проверяются где угодно. Целевая платформа продукта — только Windows, и это решение, а не следствие: пациент живёт там.
