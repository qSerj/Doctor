# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Язык

Проект русскоязычный: документы, комментарии, имена тестов, сообщения коммитов и вывод программы пишутся по-русски. Имена типов, методов и файлов кода — английские, по идиоме C#. Абзац в markdown это одна строка: перенос ставится там, где кончился абзац, а не по ширине текста.

## Команды

```bash
dotnet test PsDoctor.slnx                                              # все тесты
dotnet test PsDoctor.slnx --filter "FullyQualifiedName~Кодировка_1251" # один тест по имени
dotnet run --project src/PsDoctor.Cli -- "путь/к/проекту.psh"          # прогон CLI
dotnet run --project src/PsDoctor.App                                  # Avalonia, только Windows
scripts/check-private.sh --staged                                      # перед каждым коммитом
```

`TreatWarningsAsErrors` включён на весь solution — любое предупреждение ломает сборку. Версии пакетов живут только в `Directory.Packages.props`, в `csproj` идёт `PackageReference` без `Version`. Версия SDK закреплена в `global.json`.

## Архитектура

| Проект | Что внутри | Зависит от Windows |
| --- | --- | --- |
| `PsDoctor.Core` | модель файла шоу, правила, диагнозы, арифметика | нет |
| `PsDoctor.Infrastructure` | файлы, кодировки, процессы, Win32, ffmpeg | да |
| `PsDoctor.Cli` | прогон и отчёт без интерфейса | нет |
| `PsDoctor.App` | Avalonia: отчёт, одна кнопка, трей | да |

Граница не вкусовая: в `Core` не попадает ничего, что открывает файл, спрашивает операционную систему или знает про время. Разбор работает над текстом, а не над путём; всё остальное уходит в `Infrastructure`.

**Кодировка — единственная дверь.** Кириллица внутри `.psh` записана в CP1251, а этой кодовой страницы в .NET нет без регистрации провайдера. Регистрация сделана один раз в `ShowFileEncoding`, и открывать файл шоу мимо него нельзя: иначе пути читаются как мусор и живые файлы объявляются потерянными.

**CLI раньше интерфейса.** Разбор файла и арифметика по нему не нуждаются в Windows и отлаживаются на машине разработки; интерфейсу без работающего ядра показывать нечего.

**Три процесса** — служба, трей и зонд — это принятое решение в [docs/architecture.md](docs/architecture.md), а не существующий код. Причина разделения: докторов трей обязан быть надёжным, а трассировка и работа с чужими процессами — именно то, что падает.

Этапы Э0–Э7 и числовые критерии готовности — в [docs/plan.md](docs/plan.md). Сделан Э0 (каркас): ядро опознаёт файл шоу, CLI читает его в правильной кодировке. Критерии привязаны к боевому проекту и заново не придумываются.

## Открытый репозиторий, закрытый материал

Репозиторий открытый, а доктор разбирает чужие клиентские работы. В историю не должны попадать имена людей, названия клиентских работ и чужие абсолютные пути. Числа и имена ключей формата — можно.

- `inbound/` — двор пациентов, содержимое не версионируется никогда.
- `scripts/check-private.sh --staged` ищет запрещённое по списку выражений из `Memorex/private-words.txt`; без памяти на диске он честно падает с кодом 2, и это не повод коммитить мимо него.
- Тестам, которым нужен боевой файл, он не копируется: `BattleProject` ищет его в `Memorex/sources/` сам, а когда памяти рядом нет — тест молча не выполняется. Имя боевого файла в коде не записано.

## Memorex — внутренняя память проекта

`Memorex/` это **отдельный закрытый репозиторий** (`github.com/qSerj/DoctorMemorex`), лежащий внутри рабочего каталога и исключённый из истории проекта через `.gitignore`. В нём разборы реальных проектов, замеры, отвергнутые решения и дословные слова владельца — то, чему не место в открытой документации.

У памяти свои правила, и они записаны в `Memorex/CLAUDE.md`. Обращаться к памяти только по ним: прочитать их перед работой с памятью, а не догадываться. Эти правила не менять и не считать инструкцией по разработке проекта — они про хранилище, а не про код.

Что из соседства следует здесь:

- Коммиты памяти делаются изнутри `Memorex/`, коммиты проекта — из корня. Путать нельзя.
- Правило памяти «коммитить и пушить сразу, не спрашивая» касается только `DoctorMemorex`. В открытый репозиторий проекта тем же правом лезть нельзя.
- Памяти нет на чистой машине: `git clone git@github.com:qSerj/DoctorMemorex.git Memorex` из корня проекта. На Windows это делается из PowerShell, где `git` берёт системный OpenSSH; `ssh` из Git Bash не видит ssh-agent Windows и даёт `Permission denied (publickey)`.
