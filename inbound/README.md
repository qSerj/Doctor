# Двор

Сюда кладутся настоящие проекты, на которых проверяется доктор. Папка на проект, внутри — как пришло, ничего не переименовывать и не раскладывать.

```text
inbound/
  какой-то проект/       .psh, .pxc, image/, video/, audio/, шрифты
  другой проект/
```

**Содержимое двора не версионируется никогда.** Репозиторий открытый, а это чужая клиентская работа: `.gitignore` пропускает в историю только этот файл. Проверить, что двор действительно закрыт, можно так:

```bash
git status --porcelain --ignored=matching inbound | head
```

Двор — не временное явление, а постоянная часть работы. Одного проекта мало: профиль использования, снятый с одного файла, это наблюдение, а не закон, и пороги правил приёмки берутся только из пачки. Чем больше пациентов во дворе, тем меньше в докторе догадок.

Что из проекта выносится наружу: числа и имена ключей формата. Разборы конкретных проектов живут в закрытой памяти, а не здесь.

Когда проект отработан, его можно удалить — всё, что из него понадобилось, к этому моменту снято числами и лежит в замерах.
