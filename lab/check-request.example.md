# Задание проверки

## Цель

Кратко сформулируйте проверяемое изменение и условие, при котором оно проявляется.

## Команда владельца

```bash
python3 lab/run-check.py --exchange "$LAB_EXCHANGE" --id <новый-id> --request <путь-к-этому-файлу> -- <команда> <аргументы>
```

Запускать из корня репозитория. Не передавайте секреты в аргументах: команда сохраняется в `run.json`.

## Ручная проверка

Опишите действия владельца и наблюдаемый результат. Если ручной проверки нет, напишите «Нет».

## Ожидаемые свидетельства

Укажите ожидаемый код завершения, файлы в `results/`, строки журнала или скриншоты, которые нужно приложить к пакету.

## Версия и условия

Укажите версию приложения/инструмента, параметры стенда и иные условия, существенные для сравнения результатов.
