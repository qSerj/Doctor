# Формат файла шоу

Статус: **Согласовано** в части, снятой с боевого проекта; всё, чего в нём не встретилось, помечено отдельно.

Проект лежит в двух файлах. `.psh` — обычный текст `ключ=значение` с CRLF; у разобранного проекта это 35904 строки и 1.7 МБ. Рядом `.pxc` — двоичный собранный пакет со всеми медиа внутри, 192 МБ, и он не нужен: всё описание в `.psh`, а медиа лежат папками рядом.

Первая строка — сигнатура:

```text
Photodex(R) ProShow(TM) Producer Show File Version=0
```

Кириллица внутри файла — в CP1251. Это первая практическая ловушка: под UTF-8-локалью наивная проверка «существует ли файл по этой ссылке» объявляет потерянными вполне живые видео.

## Устройство

Иерархия: шоу → `cell[]` (слайд) → `images[]` (слой) → `keyframes[]`. На уровне шоу отдельно лежат `sound[]`, библиотека `captionStyle[]` и `modifier[]`.

Единицы целочисленные и масштабированные: `zoomX=10000` означает 100%, `videoFrameRate=29970` означает 29.97, время в миллисекундах.

Три вещи, которых из меню программы не видно.

**Слайд живёт в трёх фазах.** У каждого ключевого кадра есть `timeSegment` со значениями 1, 2, 3, встречающимися примерно поровну; рядом различаются `timestamp` и `segmentTimestamp`. Слой продолжает двигаться сквозь переход: переход не эффект между двумя слайдами, а общая зона, которой оба слайда владеют.

**Переход — это мини-слайд.** У `cell[].customTransition` есть собственные `images[]` со своими `keyframes[]`. Движок один и на слайд, и на переход; отдельной машины переходов не существует.

**Слой не обязан быть картинкой.** `useGradient` и `gradient.colormap[]` — заливки и градиенты полноценные слои. `isMaskingLayer` — маска это тоже слой, только помеченный. Для видео: `isVideo`, `videoStartTime`, `videoEndTime`, `videoLength`, `loopVideo`, `videoSpeed`, `useCropping`, и даже собственные `transitionInId` / `transitionOutId` у слоя.

## Что из файла вычитывается

**Словарь.** Каждая функция программы оставляет ключ — это исчерпывающий список возможностей без маркетинга.

**Онтология.** Как устроена сцена; к чему авторы пришли за пятнадцать лет.

**Профиль использования.** Какие ключи реально несут неумолчальные значения.

## Чего не вычитывается

Поведение за именем. `modifier[].action[].functionId=1001` — модификаторы это маленькая машина выражений, и что такое функция 1001, из имени не следует. `styleFlags=-31777`, `excludeStyleFlags=915` — битовые маски, значения битов только подбором. `transId=2` не говорит, как переход выглядит. Гамма и цветовое пространство композитинга не записаны нигде.

Для доктора это не препятствие: он читает проекты, а не воспроизводит картинку.

## Открытое

Какой именно ключ считать шириной вывода при расчёте нужного разрешения. В шапке разобранного проекта одновременно есть `displaySizeX=704`, `videoSizeX=720` и `outputImageSizeX=1024`, и какой из них определяет масштаб на экране — **не установлено**.

Порождение файла шоу. Формат текстовый, значит синтетическое шоу из сотни одинаковых слоёв можно собрать и замерить время его загрузки. Это единственный способ превратить вопрос «какие форматы для ProShow съедобнее» из мнения в число. Не проверено.

Переживает ли программа правку файла шоу со стороны: есть ли контрольные суммы и что происходит при рассинхроне с `.pxc`. Не проверено, гейт для этапа лечений.
