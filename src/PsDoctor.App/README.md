# PsDoctor.App

Окно оператора: Avalonia, отчёт, одна кнопка, трей. **Сегодня это каркас Э0 с окном-заглушкой** — работающего интерфейса здесь нет.

Не принимать состав этой папки за решение об интерфейсе: решение лежит в раунде проектирования, а код до него ещё не дошёл.

## Что здесь будет

Главное рабочее место по [окну](../../design/tier1/window.md) и [трею](../../design/tier1/tray.md): список находок с решениями, выполнение одной кнопкой, уход в трей при закрытии. Слова — по [словарю фраз](../../design/tier1/wording.md); второй копии формулировок не заводится, потому что две копии однажды разойдутся.

Этап — [Э7](../../docs/plan.md), и критерия у него пока нет.

## Граница

**Слова живут здесь и только здесь.** В отчёте CLI и в фактах наблюдателя человеческих фраз нет вовсе; сюда же они не копируются из них, а пишутся один раз.

**Окно не повышается в правах.** Это не осторожность: у процесса с повышенными правами перестаёт работать перетаскивание файлов из проводника, и доктор не смог бы принять брошенный мышкой файл шоу.

Avalonia, а не WPF: WPF навсегда закрыл бы общий код с соседним проектом владельца.

## Тесты

Своих нет и до Э7 не будет.
